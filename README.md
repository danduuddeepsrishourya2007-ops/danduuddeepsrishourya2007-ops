## What I'm Building

### NEXUS

**Large-scale decision simulation for high-stakes environments.**

NEXUS lets organizations test decisions inside simulated environments before deploying them in reality.

The architecture separates:

**Deterministic simulation engine** → **Agent reasoning** → **Validated decisions** → **Simulation metrics**

The goal is to make AI-driven decisions measurable through things like:

* emergent risks
* resource bottlenecks
* system availability
* incident spread
* recovery time
* policy outcomes
* agent decision latency

> The simulation is the product. The LLM is a decision-making component inside it.
